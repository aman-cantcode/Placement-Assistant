About

We built the tool we wish existed during placement season.

Placement Assistant exists to answer one question clearly: how well do you actually match a given job, and what would close the gap. Everything else — the roadmap, the interview practice, the chat — is built around that one answer.

What it actually does

Upload your resume once. From there, every job description you paste in gets its own analysis: an ATS match score with matched and missing skills called out individually, a roadmap built around what's actually missing for that role, a set of interview questions written for that specific job, and a chat that has read both your resume and that JD — not generic advice recycled across every user.

Your data

How we handle your data

  • Your login session token lives only in your browser's memory while you're using the app — never somewhere a script could quietly read it later.
  • The token that keeps you logged in over longer periods sits in a cookie your browser controls directly — JavaScript can't touch it at all.
  • If that longer-lived token is ever reused after it's already been replaced — a sign it may have leaked — every session on your account is signed out automatically as a precaution.
  • Passwords are never stored as plain text, and reset links expire after 15 minutes and only work once.
  • Analysis, roadmaps, and interview questions are generated with Google's Gemini models, routed through infrastructure that isn't reachable from the public internet — only our own server can reach it.
Cost

A quick note on cost

There's no payment system here yet — usage is effectively unlimited while the core product is still being built out. That's expected to change eventually, but for now, it's free to use.

FAQ

A few common questions

Do I need to re-upload my resume for every job?

No — upload it once and it's reused automatically for every job description you check after that. Each analysis keeps its own snapshot, though, so updating your resume later won't change results you've already generated.

What file formats does it accept for my resume?

PDF and Word documents (.doc / .docx), up to 5 MB.

What happens if an analysis fails?

Occasionally the scoring step can fail, usually from a transient issue. You can delete a failed analysis from its page and submit the job description again.

Is the chat specific to each job, or shared across all of them?

Specific to each one. The chat for a given analysis only knows about that job description and your resume, not your other analyses.
